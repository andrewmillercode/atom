## What's New

- **Client/server split** — `atom` is now the TUI client, `atoms` the background session server; the client starts the server automatically.
- **Auto-update** — release builds self-update from GitHub releases.
- **Math and diagrams in the TUI** — LaTeX rendering (kitty graphics) and a new `visualize` tool for Mermaid architecture/data-flow diagrams.
- **Providers** — fixed Bedrock errors; provider/model listing improvements.
- **Approvals & sandbox** — fewer duplicate approval prompts
- **Dev installs** — `make install-dev` installs `atomdev`/`atomsdev` with isolated dev state; `make uninstall` fully removes atom.
