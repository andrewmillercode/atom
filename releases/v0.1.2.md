## What's New

- **web_fetch tool** — agents can now fetch and read web pages directly.
- **Themes** — 15+ built-in color themes (Catppuccin, Dracula, Gruvbox, Tokyo Night, Rose Pine, and friends).
- **Rendering overhaul** — substantially improved markdown rendering, plus inline LaTeX math in messages.
- **Fullscreen views** — overlays and blockers can now open in a fullscreen view with proper headers.
- **OpenAI Responses API** — new `responses` provider backend, model catalog improvements via models.dev, and smarter request retries.
- **Subagent improvements** — better subagent handoff behavior and `send` message routing.
- **Fixes** — skill parsing, mouse click handling, status bar polish, and session store fixes.
