## What's New

- **`atom uninstall`** — new subcommand that removes atom binaries, state, and the `install.sh` PATH entry. Mirrors `make uninstall`; pass `-y` to skip the prompt.
- **Fix default init** — when no saved model is present, falls back to opencode-zen's mimo-v2.5-free tier instead of forcing the provider picker. Default compaction provider/model switched to opencode-zen/mimo-v2.5-free.
- **`/fork` overlay redesigned** — borderless inline search with caret, title/description chrome, and filterable message list instead of the old bordered picker.
- **Theme picker color swatches** — hex color chips rendered after each theme name in the theme list.
- **Sandbox approval block conversion** — when approval is requested, the preceding Bash block is converted in-place to a Sandbox block instead of stacking a fresh one.
- **Image prep gate** — sending is blocked while pasted images are being normalized; a "preparing image…" message is shown instead.
- **Compaction threshold raised** — auto-compact token threshold increased from 150k to 256k; headroom reduced from 20k to 18k.
- **Links rendering fix** — only markdown `[label](url)` syntax and explicit `linkify_path` now produce OSC 8 hyperlinks; bare prose URLs no longer leak clickable regions.
- **Removed legacy Go code** — `main.go`, `server.go`, `tui.go`, `session.go`, `preview.go`, `compaction.go` and associated tests deleted; Rust is now the sole implementation.
- **New reusable fullscreen view template** — `fullscreen_view.rs` refactored into a shared `ViewSpec` layout (title, description, search, list, footer) used by all overlays.
- **Build artifacts added to `.gitignore`**.
